# Rascunho · arquitetura de abas por papel

Base: áudio da Larissa (17/07). Ela quer **capa + menu ☰** (já feito) e está migrando de
"abas por conteúdo" para **"abas por papel"**. Este é um rascunho para vocês fecharem
item a item · **nada disto está no site ainda** (só a capa/menu e a paleta mais clara já entraram).

## 1. O que ela pediu (resumo do áudio)

- **Capa:** uma imagem grande dela **em cena (Zelda)** + "Larissa da Matta" + uma frase com os papéis.
- **Papéis citados:** Atriz · Dramaturga · Performer · Educadora · Pesquisadora.
  "Dançarina" · ela está **tirando** ("tô pensando muito sobre o dançarina, acho que vou tirar").
- **Menu ☰** · cada item abre uma "aba/página dentro da página".
- **Redistribuir as informações:**
  - **Idiomas** → dentro de **Atriz** e de **Pesquisadora**
  - **Características** (físicas) → dentro de **Modelo** e de **Atriz**
  - **Formação** → só dentro de **Sobre**
  - **Habilidades** → só dentro de **Atriz**
- **Frases de impacto** ("do palco à tela, da dança à moda...") · tendendo a **tirar**.
- **Pesquisa** · aba pequena, **só texto** (já feito).

## 2. Proposta de menu (duas opções)

**Opção A — literal (papéis como ela listou):**
`Início · Sobre · Atriz · Dramaturga · Performer · Modelo · Pesquisadora · Educadora · Mídia · Currículos · Contato`

**Opção B — híbrida (recomendo):**
`Início · Sobre · Atriz · Dramaturga · Performer · Modelo · Pesquisa · Aulas · Mídia · Currículos · Contato`
(mantém o efeito "por papel", mas usa "Pesquisa" = Pesquisadora e "Aulas" = Educadora,
que já estão prontas e cheias)

## 3. O que entra em cada aba (proposta)

| Aba | Conteúdo |
|---|---|
| **Início** | capa: foto de cena + nome + frase dos papéis |
| **Sobre** | bio + **Formação** (só aqui) |
| **Atriz** | Teatro/TV/Cinema + destaque *A Última Valsa de Zelda* + **Idiomas** + **Características** + **Habilidades** |
| **Dramaturga** | autoria (*A Última Valsa de Zelda*) + *Dramaturgias do Corpo* como dramaturgia |
| **Performer** | corpo · dança urbana · live-painting (*Corpo e Cor.*) |
| **Modelo** | fashion film + marcas + **Características** |

| **Aulas** (Educadora) | espanhol · inglês (conversação) · curso livre de teatro |
| **Mídia** | fotos · vídeos · imprensa · publicações · entrevistas |

| **Contato** | e-mail · agência (Acervo de Atores) · redes |

## 4. Pontos para decidir com ela (não dá para chutar)

1. **Lista final de papéis** · fica "Dançarina" ou "Performer" já cobre a dança?
2. **Dramaturga · Performer · Educadora têm pouco conteúdo hoje** · viram abas próprias
   (podem parecer "vazias") ou entram como blocos dentro de Atriz/Sobre? → é o motivo da Opção B.
3. **Frases de impacto** · tira ("do palco à tela...") ou mantém?
4. **Idiomas e Características repetidos** em duas abas cada · ela pediu assim; confirmar.
5. **Fotos/Vídeos** · ficam juntos em "Mídia" (como está) ou distribuídos por papel?
6. **Modelo** · mantém como aba mesmo tirando "Dançarina"?

## 5. Recomendação

Ir de **Opção B (híbrida)**: entrega o efeito "abas por papel" que ela quer, sem criar
abas magras. Quando ela mandar mais material (foto de cena da Zelda para a capa, fotos de
Modelo · Baby Kerr / Thiago / "fotografia dela", novos artigos, outras redes), a gente
enche as abas mais fininhas e, se fizer sentido, promove Dramaturga/Performer a abas próprias.

> Enquanto isso, a **paleta já ficou mais clara** (pedido dela) · marrom e verde mantidos,
> só menos escuros. As opções de **cor e fonte para ela escolher** ficam prontas quando você pedir.
